## 2026-07-03: 表格行操作菜单底部防溢出

**本地补丁：**

- 新增 `floatingMenuPosition` 公共定位工具，将浮层位置按视口边界夹紧，并返回可用最大高度。
- 账号管理行操作 `AccountActionMenu` 在 Teleport 到 body 后读取真实菜单尺寸，重新校正 top/left，并设置 `max-height` 与 `overflow-y: auto`。
- 用户管理行操作菜单复用同一套定位逻辑，避免同类“更多”菜单在底部行打开后超出屏幕。
- 初始定位仍保留桌面端靠近点击点、移动端围绕触发按钮的原交互；本次不改业务菜单项和按钮行为。

**涉及文件：**

- `frontend/src/utils/floatingMenuPosition.ts`
- `frontend/src/utils/__tests__/floatingMenuPosition.spec.ts`
- `frontend/src/components/admin/account/AccountActionMenu.vue`
- `frontend/src/views/admin/AccountsView.vue`
- `frontend/src/views/admin/UsersView.vue`
- `docs/fork-maintenance/2026-07.md`

**验证：**

```bash
pnpm --dir frontend exec vitest run src/utils/__tests__/floatingMenuPosition.spec.ts src/components/admin/account/__tests__/AccountActionMenu.spark_shadow.spec.ts src/views/admin/__tests__/AccountsView.sparkShadow.spec.ts src/views/admin/__tests__/UsersView.spec.ts
pnpm --dir frontend run typecheck
pnpm --dir frontend run build
git diff --check
```

**同步官方后的复查：**

- 搜索 `floatingMenuPosition`、`clampFloatingMenuPosition`、`getActionMenuPosition`、`AccountActionMenu`、`actionMenuContentRef` 和 `action-menu-content`。
- 如果官方后续引入统一 Dropdown / Popover / Floating UI，优先收敛到官方浮层实现，但必须保留“按真实菜单高度校正位置”和“短屏内可滚动”的行为。
- 回归账号管理、用户管理以及后续新增的表格行“更多”菜单：在最后几行打开菜单时，底部操作项应保持在视口内可点击。
